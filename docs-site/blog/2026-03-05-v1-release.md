ContextCore 1.0.0 is here — GPU-accelerated context management for on-device AI agents.

<!-- truncate -->

## What's Included

- **AgentContext** — single-actor public API: append, buildWindow, checkpoint
- **4 memory types** — working, episodic, semantic, procedural
- **5 Metal compute shaders** — relevance, recency, attention, compression, consolidation
- **Automatic consolidation** — background dedup, fact promotion, contradiction detection
- **Progressive compression** — extractive fallback, no LLM required
- **Session persistence** — atomic checkpoints with full state restore

## Performance

Measured on M2 Max, macOS 26.0:

| Operation | Result |
|---|---|
| buildWindow p99 (500 turns, 4096 budget) | 6.54ms |
| consolidate p99 (2000 chunks) | 19.71ms |
| GPU memory | ~1 MB |

## Requirements

- Swift 6.2+
- iOS 17.0+ / macOS 14.0+ / visionOS 1.0+
- Metal-capable device
- [MetalANNS](https://github.com/christopherkarani/MetalANNS)

## Installation

```swift
dependencies: [
    .package(url: "https://github.com/christopherkarani/ContextCore.git", from: "1.0.0")
]
```

## Quick Start

```swift
import ContextCore

let context = try AgentContext()
try await context.beginSession(systemPrompt: "You are a senior Swift engineer.")
try await context.append(turn: Turn(role: .user, content: "How do I fix this actor leak?"))

let window = try await context.buildWindow(
    currentTask: "Debug actor isolation",
    maxTokens: 4096
)
let prompt = window.formatted(style: .chatML)
```
